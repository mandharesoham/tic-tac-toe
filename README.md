# 🎮 Tic Tac Toe

A simple and interactive Tic Tac Toe game built using HTML, CSS and JavaScript.

## 🚀 Live Demo

[Play Tic Tac Toe](https://mandharesoham.github.io/tic-tac-toe/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Two-player gameplay
- Win detection
- Draw detection
- Reset game functionality
- New game functionality
- Responsive design
